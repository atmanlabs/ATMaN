## 1. What Was Built

### Part 1 — Cockpit Flight Deck & Tool Execution Engine (`cockpit.py`)
- **Permission Fence Gated:** All flight instruments and tools operate strictly behind the config permission fence. Tools not in `permissions.tools.allowed` or listed in `permissions.tools.denied` raise `PermissionFenceError` and are quarantined by the Judge.
- **Permitted Flight Instruments:**
  1. `system_telemetry`: Real-time hardware telemetry querying:
     - NVIDIA GeForce RTX 3050 VRAM usage, total, and GPU utilization via `nvidia-smi`.
     - Host RAM load, used, available, and total memory via standard library `ctypes` (`GlobalMemoryStatusEx` on Windows, zero external packages).
     - Process runtime uptime counter.
  2. `clock_timer`: Current local time (12-hour formatted with AM/PM), local date, and mind session elapsed uptime.
  3. `workspace_inspect`: Safe, path-jailed file listing and text file inspection within `exo-live`:
     - Path traversal (`../`, absolute paths) is strictly blocked.
     - Access to `exo-private`, `tsc.exo.private.json`, `operator.auth.json`, and `stage1-seal.json` is strictly forbidden.
  4. `memory_query`: Searches persistent PSC memories and grounded truths learned from the operator.
  5. `calculator`: Safe mathematical/arithmetic evaluation using Python's AST parser (no `eval()` or code execution).
- **Cockpit Flight Deck Dashboard (`render_dashboard()`):**
  - High-visibility ASCII telemetry dashboard displaying GPU VRAM gauges, Host RAM gauges, process uptime, sensory subsystems (Ollama, Camera, Voice), and permission status.

### Part 2 — Continuous Loop & Voice Chat Integration (`loop.py`, `reason.py`, `voice.py`)
- **On-Demand Tool Invocation:**
  - In `reason.py`: LLM system prompt informed of cockpit flight instruments. Intent extraction automatically matches operator telemetry, time, workspace, memory, and calculation queries.
  - In `loop.py`: `MindLoop._dispatch_action()` dispatches `tool_call` actions to `Cockpit.execute_tool()`.
  - In `voice.py`: `talk_turn()` speaks tool execution outputs aloud via Piper TTS (`action_res.get("action") in ("respond", "tool_call")`).
- **Interactive Console Command:**
  - Operator can type `cockpit` or `flightdeck` in the interactive console loop at any time to inspect the full instrument dashboard.

### Part 3 — Configuration Parser Fix (`config.py`)
- **The Issue:** `parse_simple_yaml()` had a stack-popping bug on YAML list items at identical indentation levels, causing only the last list item to be preserved.
- **The Fix:** Integrated standard `PyYAML` (`yaml.safe_load`) when available, backed by an indentation lookahead pure-Python parser fallback that properly handles YAML lists and nested dictionaries with zero external dependencies.
