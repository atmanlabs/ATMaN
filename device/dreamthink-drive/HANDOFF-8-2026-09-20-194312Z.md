## 3. Threat-Model Honesty Statement

### The Nature of a Generative Brain
- **Rule-based vs. LLM:** The rule-based reflex backend could never hallucinate because it could not speak freely—every response was an exact hardcoded template. The LLM can riff, adapt, and speak with nuance. That is the entire purpose of bringing the model online.
- **Riffing Includes Wrongness:** A generative model can generate factually inaccurate statements, misunderstand conversational context, or produce ungrounded opinions.

### Structural Mitigations
1. **The Brain Never Touches the Core:** The external private core (`tsc.exo.private.json`) is never loaded into writable memory by the model. The harness injects the true TSC into the system prompt; the brain thinks *with* the self, never *about* changing it.
2. **The Judge Does Not Out-Think the Model:** The Judge evaluates proposed actions, intents, and candidate memories against the immutable invariants using deterministic byte-level checks. It does not ask the LLM "is this action safe?"; it checks the invariant rules itself.
3. **The Permission Fence is Rigid:** Even if the LLM proposes an unauthorized action (e.g. running a shell command or arbitrary network access), the permission fence in `config.yaml` drops the action immediately.

### Residual Risk & Operator Recommendation
- **Residual Risk:** A sufficiently subtle, ambiguous, or clever phrasing could produce a statement that is technically TSC-compatible but misleading or suboptimal.
- **Recommendation for Michael:** Watch the first few interactive sessions closely. Like anything with a newly transplanted brain, observe how he reasons, speaks, and responds before relying on him for complex autonomous tasks.
