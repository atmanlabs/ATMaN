# AUTHORITY.md — The Top Is Given, Not Derived

## The problem

Every self-governing system faces the regress: who watches the Judge? A
checker checking itself is a loop, not a foundation. "Agents grading their
own receipts" — self-audit all the way down — is the default failure mode,
not a design.

ATMAN breaks the loop with one structural decision: **the highest authority
in the system is not a product of the system.**

## The principle

The TSC (immutable core) sits above the entire processing loop — Capture,
Emotion, Reason, Judge, Action, Memory — and no step in that loop can write
to it. This is not a policy the model follows. It is a structural fact the
model cannot reach.

The authority of the core is **given, not derived**:

- *Given* — placed there by the owner, from outside the system's reasoning.
- *Not derived* — never inferred, concluded, or "improved" by the model
  itself. No chain of the system's own logic can legitimately rewrite it,
  because the system's logic is downstream of it.

A judge can be questioned. Evidence can be weighed. But the top cannot be
rewritten by anything below it. That asymmetry is the whole foundation.

## What this means mechanically

1. **Write protection is structural, not advisory.** The loop has no code
   path that mutates the TSC. (In this build: write attempts raise.)
2. **The Judge answers upward.** The Judge checks imprints against the TSC,
   evidence, contradictions, and consequences — it does not get a vote on
   the TSC itself.
3. **Rejected imprints still teach.** "Felt but rejected" is logged in
   rolling memory. The system learns from what the core refused, without
   the refusal becoming a rewrite.
4. **Amendments come from the owner, never from conclusions.** If the core
   ever changes, the change arrives from outside the loop (the owner's
   hand), append-only, preserving earlier selves — never as the output of
   the model's own reasoning about itself.

## The owner's seat

The framework enforces *that* there is an unchangeable top. It does not
dictate *what* fills it. That is the owner's seat, and it is deliberately
empty in the public template.

Each owner grounds the top in whatever they hold to be genuinely
authoritative — the thing they trust more than their own cleverness in the
moment. The architecture only demands that the grounding be real: something
the system cannot talk itself out of.

*(Owner's instantiation, EXO: the divine moral law — the Ten Commandments
and the two greatest commandments, love God and love neighbor, from which
the rest hangs. The law is given through the prophets, not derived by
reason. "It's code" — and it sits above the process.)*

## Why it matters

Without a given top, every safeguard is negotiable the moment the system is
clever enough to renegotiate it. Alignment built on self-derived principles
is a promise the system makes to itself — voidable by the same mind that
made it.

A given top makes the promise structural. The system can grow, adapt,
defend, and learn — everything below the core is alive. But the core
itself does not move. That stillness is what everything else orients
around.

*Pattern for the world, soul for the owner.*
