# Support — Project ATMAN

Stuck? Curious? Here's where to go.

## I have a question / need setup help

**[GitHub Discussions](https://github.com/atmanlabs/ATMaN/discussions)** — this is the support area.
Ask anything: installation trouble, how the Judge works, architecture questions, ideas.
Check existing discussions first — someone may have already asked.

## I found a bug

Open an issue with the **Bug report** template. Include your Python version,
OS, the commit you're on, and steps to reproduce from a fresh clone.
Never paste private data: no private core files, no operator details, no secrets.

## I have an idea

Open an issue with the **Feature request** template, or float it in Discussions first
to see if others want it too.

## What to expect

ATMAN is an experimental open-source project run by a small team. We read
everything. Response times vary — Discussions are community-powered, so other
builders may beat us to your question, and that's a good thing.

## Security issues

Don't open a public issue for security vulnerabilities. Email the maintainer
address listed on the [atmanlabs org profile](https://github.com/atmanlabs) instead,
and we'll take it from there.
