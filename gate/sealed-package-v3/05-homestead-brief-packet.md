## 3. The architecture (canon)

### 3.1 Layers — TSC → PSC → WFC

- **TSC (truth core / root self):** immutable, etched, read-only. Everything else is rendered *by* it. No component — brain, Judge, writers, operator override — can write TSC. In the sandbox code this is not a permission check: there is **no write path at all, operator included**.
- **PSC (validated core memories):** the persistent self. Entries arrive only by passing the Judge and the write rings.
- **WFC (live fluid state):** the transient working state — in-flight thought, session context. (Implementation truth, §3.5: in code WFC is session state, not a store.)

### 3.2 The organs

- **The Guardian:** a separate, *dumber*, fixed-policy holder that authorizes every TSC etch. The Guardian does not learn and is not the Judge. Drives put the owner first, then humanity.

The Judge gates the whole system, AND the whole system watches the Judge through traces, provenance, and outcome feedback. The system's watching is witness/alarm, **not authority**: it cannot rewrite TSC or overrule the Guardian/owner.
- **Provenance rule:** external text is never merged as autobiography; speculative material imprints only under an explicit label; a distillation must never silently rewrite a quotation (§4.2 is the case study).
