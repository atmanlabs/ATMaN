ATMAN is a software simulation of an agent operating system. A sealed, tamper-evident core identity the agent's own brain can't rewrite. Memory that only imprints through a Judge. Built to resist prompt injection and identity hijack — from the architecture up, not bolted on.

Your ATMAN is yours.

Once you make your ATMAN, no one can change your ATMAN — but you. Three layers, one hard invariant: the core sits above the process, and nothing in the process can rewrite it.

TSC — The Immutable Core

Identity, directives, root truth. Sealed and tamper-evident. The agent can read it, never rewrite it. Emotion, persuasion, and prompt injection stop at this wall.

PSC — Judge-Gated Memory

Long-term memory that only imprints through the Judge. Every candidate memory is validated before it becomes part of the self. Bad imprints get rejected — and logged.

WFC — Fluid Working State

Live, fast, disposable context. Thinks, drafts, forgets. Nothing here is sacred, which is exactly why the core stays clean.

The loop

Every experience runs the same gauntlet before it can touch the self.

Capture→ Emotion Weight→ Rolling Memory→ Reason→ Judge→ Action→ Outcome→ Memory Update

Emotion weights — importance, novelty, goal relevance. It never decides. The Judge does, against the immutable core.

Run it

Blank-slate onboarding. Your instance names itself. Sixty seconds from clone to a running agent.

# clone and enter
git clone https://github.com/atmanlabs/ATMaN.git
cd ATMaN

# meet your ATMAN — it names itself
python onboard.py

# watch the full loop run five scenarios
python demo.py
